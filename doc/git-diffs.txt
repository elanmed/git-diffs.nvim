`GIT-DIFFS.NVIM`                                    *git-diffs-git-diffs.nvim*


A minimal plugin for comparing Git file versions in a side-by-side diff view.


------------------------------------------------------------------------------
FEATURES                                                  *git-diffs-features*


- 1 source file (~500 LOC), no dependencies
- Compare worktree, index, HEAD, upstream, and merge-base versions in a
  side-by-side split with file list

------------------------------------------------------------------------------
EXAMPLE CONFIG                                      *git-diffs-example-config*


>lua
    vim.g.git_diffs = {
      smooth_scroll = true,
    }
    
    vim.api.nvim_create_autocmd({ "FileType" }, {
      group = vim.api.nvim_create_augroup("GitDiffViewRemaps", { clear = true }),
      pattern = "git-diffs-view-file-list",
      callback = function()
        vim.keymap.set("n", "<c-d>", "<Plug>GitDiffViewScrollDown", { buffer = true })
        vim.keymap.set("n", "<c-u>", "<Plug>GitDiffViewScrollUp", { buffer = true })
        vim.keymap.set("n", "<leader>e", "<Plug>GitDiffViewRefresh", { buffer = true })
        vim.keymap.set("n", "o", "<Plug>GitDiffViewSwitchToBuffer", { buffer = true })
      end,
    })
    
    vim.keymap.set("n", "<leader>gd", function()
      require("git-diffs").toggle_diff_view { diff_type = "worktree-index" }
    end)
    vim.keymap.set("n", "<leader>gD", function()
      require("git-diffs").toggle_diff_view { diff_type = "worktree-head" }
    end)
    vim.keymap.set("n", "<leader>gm", function()
      require("git-diffs").toggle_diff_view { diff_type = "head-mergebase" }
    end)
<

------------------------------------------------------------------------------
PLUG REMAPS                                            *git-diffs-plug-remaps*



                                                                              
`<PLUG>GITDIFFVIEWSCROLLDOWN`          *git-diffs-<plug>gitdiffviewscrolldown*

Scroll down in the diff view (both splits simultaneously).


                                                                              
`<PLUG>GITDIFFVIEWSCROLLUP`              *git-diffs-<plug>gitdiffviewscrollup*

Scroll up in the diff view (both splits simultaneously).


                                                                              
`<PLUG>GITDIFFVIEWREFRESH`                *git-diffs-<plug>gitdiffviewrefresh*

Refresh the list of files with diffs.


                                                                              
`<PLUG>GITDIFFVIEWSWITCHTOBUFFER`  *git-diffs-<plug>gitdiffviewswitchtobuffer*

Switch to the selected file's buffer in the tab from which the diff view was
opened.


------------------------------------------------------------------------------
API                                                            *git-diffs-api*



                                                                              
`REQUIRE("GIT-DIFFS").OPEN_DIFF_VIEW(OPTS)`*git-diffs-require("git-diffs").open_diff_view(opts)*

Opens a new tab with a 3-pane diff view:

- **Old** (left): the old file version
- **New** (right): the new file version
- **Files** (bottom): list of changed files
`opts`:

- `diff_type` (`string`): one of `"worktree-index"`, `"worktree-head"`,
  `"worktree-upstream"`, `"worktree-mergebase"`, `"index-head"`,
  `"index-upstream"`, `"index-mergebase"`, `"head-upstream"`,
  `"head-mergebase"`
- `upstream_branch` (`string?`): upstream branch name (default: `"master"`)
If the diff view tab already exists, switches to it instead of creating a new
one.


                                                                              
`REQUIRE("GIT-DIFFS").TOGGLE_DIFF_VIEW(OPTS)`*git-diffs-require("git-diffs").toggle_diff_view(opts)*

Toggles the diff view: opens it if not open, closes it if already open.


------------------------------------------------------------------------------
AUTOCOMMAND EVENTS                              *git-diffs-autocommand-events*



                                                                              
`USER GITDIFFVIEWOPEN`                        *git-diffs-user-gitdiffviewopen*

Fired after the diff view opens. `data` contains `old_winnr`, `new_winnr`,
`file_list_winnr`, `old_bufnr`, `new_bufnr`, `file_list_bufnr`.


------------------------------------------------------------------------------
FILETYPE                                                  *git-diffs-filetype*


The file list buffer in the diff view uses `git-diffs-view-file-list` filetype
for custom highlighting or keymaps.
